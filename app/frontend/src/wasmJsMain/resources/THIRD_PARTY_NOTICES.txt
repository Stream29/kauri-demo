Kauri's platform host is an original Kotlin/Native implementation. It does
not compile or link the webview/webview project, and it does not ship a
third-party WebView2 loader. The Windows runtime discovery follows the
documented system WebView2 deployment model while calling the accepted
compatibility entry point directly; no upstream loader source was copied.

Linux builds also statically link the GNU libstdc++ runtime from the
Kotlin/Native GCC 8.3 toolchain. Upstream licensing and runtime exception:
https://gcc.gnu.org/onlinedocs/libstdc++/manual/license.html
